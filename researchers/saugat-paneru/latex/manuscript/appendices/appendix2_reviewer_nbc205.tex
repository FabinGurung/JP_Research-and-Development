\section*{Source and limitation}
The accompanying figure is reproduced from the photograph embedded in the researcher's 22-item review document, where it is described as a dimensional example from NBC~205:2012. It is retained as a reference to the researcher's requested plan-selection and reinforcement discussion, rather than used as an independently verified code requirement or as evidence of the reinforcement provided in any analysed ETABS model. The photographed extract must be checked against the relevant official code edition before drawing building-specific detailing conclusions. In particular, the original screenshot does not establish compliance with NBC~205:2024 or any subsequent edition.
