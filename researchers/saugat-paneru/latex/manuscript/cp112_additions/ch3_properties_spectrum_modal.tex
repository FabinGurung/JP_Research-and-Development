\subsection{Modal Analysis and Mass-Participation Extraction}
The modal-analysis dataset is retained as seven model-specific workbooks, one for each Regular, L, L1, L2, T, U, and Non-Parallel configuration. Each workbook contains the worksheet \texttt{Modal Participating Mass Ratios} with twelve modes for each retained demand block. The extracted fields include modal period, frequency, per-mode translational participation (UX and UY), and cumulative translational participation (SumUX and SumUY). The seven source workbooks are preserved with the LaTeX reproducibility project and were normalized into a 420-row dataset used to generate the modal tables. The workbook-to-table source mapping and file hashes are retained with the electronic project records.

For the printed seven-model comparison, the Soil Type C, $Z=0.40$ block is used so that the modal summary is on the same matched basis as the principal response comparison in Chapter~4. The remaining source blocks are retained in the normalized electronic dataset and are not discarded.
