\subsection{Modal Characteristics}
The latest model-specific modal-participation workbooks provide the first three modal periods together with direction-specific translational mass participation for all seven configurations. To keep the modal comparison aligned with the principal seven-model response comparison used in this chapter, the summary below uses the Soil Type C, $Z=0.40$ block from each workbook.

\input{generated/tables/modal_period_mass_z040_type_c.tex}

The first mode is predominantly X-translational for every configuration, contributing 79.09--80.32\% of the translational mass in UX. The second mode is predominantly Y-translational, contributing 74.82--80.42\% in UY. The fundamental period $T_1$ ranges from 0.649~s for L2 to 0.707~s for U; $T_2$ ranges from 0.593 to 0.674~s, while $T_3$ ranges from 0.476 to 0.569~s. These differences indicate modest but measurable changes in the dynamic characteristics among the investigated plan configurations and do not by themselves establish a performance ranking.

\input{generated/tables/modal_cumulative_mass_z040_type_c.tex}

For every configuration, cumulative translational participation exceeds 90\% by Mode~4 in the X direction and by Mode~5 in the Y direction. The corresponding cumulative values at the threshold modes are approximately 91.94--92.39\% in X and 90.94--92.39\% in Y. By Mode~12, the source workbooks report 100\% cumulative translational participation in both horizontal directions for all seven configurations. The modal results therefore provide an explicit direction-wise participation check in addition to the period comparison used elsewhere in the response discussion.
