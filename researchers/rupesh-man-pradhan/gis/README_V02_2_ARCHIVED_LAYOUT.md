# Rupesh GIS static atlas — preserved V02.2 predecessor

V02.2 is a historical thesis-layout draft. It had a schematic Nepal inset and
dense within-ward E/NE labels; V02.3 replaced that with distinct ward fill colors,
a two-column count key and a coarse sourced Nepal country locator.

No scientific validation is implied by this UI/design version change.
