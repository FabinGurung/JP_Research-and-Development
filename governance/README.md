# Research governance foundation

Read [ADR 001](ADR-001-research-authority-boundaries.md), then the repository CURRENT.json.

The `bootstrap/JP_A9_Research_Governance/` directory is a standalone, validated repository package available within this existing research repository. It holds schemas, operational code, tests and SOPs. It contains no imported scientific records, private Drive pointers or asserted thesis sequence state.

A separate private repository is optional if detailed or restricted records justify it. Existing live histories remain in their owning authorities. R&D is the research publication layer; A7 is the identity and routing layer; Drive remains the scientific authority.
