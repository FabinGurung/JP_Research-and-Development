# Visibility and evidence

Public repositories permit schemas, synthetic tests and approved public metadata. Restricted pointers and private provider identifiers require a private repository and explicit disclosure policy. Do not store credentials, private communications, proprietary Times New Roman font files, large PDFs or mirrored scientific ZIPs. Drive remains the artifact authority. Store actual pointer/checksum/byte count and release identity after live verification. Restrict public projections independently from repository access.

The validator scans for credential markers, private-key blocks, forbidden binary extensions and restricted pointers in public mode. This is a guard, not proof that arbitrary free text contains no confidential information; review disclosures before publication.
