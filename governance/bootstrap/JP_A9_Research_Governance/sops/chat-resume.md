# Compact resume

Read only root CURRENT, project identity, lane CURRENT, latest closed event, active debt and applicable SOPs. Fetch exact Drive sections on demand. Use `python scripts/a9.py resume --project <slug> --lane <lane>` for a short handover.

Handover fields: authority/repository identifiers, CURRENT, latest closed event, open debt, next boundary and do-not-replay. Aim below 3,000 tokens. One chat owns one lane. Close at a safe boundary before context becomes crowded. Never claim knowledge of a precise remaining context percentage when the interface provides no measurement.
