## Explicit technical findings

1. **PU-FMT-016 — 3× logo override:** University shared control specifies a **1.6-inch** emblem slot. Saugat's requested production cover uses a **4.8-inch** slot and a true 3× displayed image; documented as user-authorized exception, not silently certified as conforming.
2. **PU-FMT-007 — no-hyphenation:** The v2.4 production PDF contains 182 potential line-end broken words; the v2.5-RC1 source-only strict hyphenation profile reduces this to **5**, still not zero. It preserves **115 A4 pages**, retains 81 embedded image occurrences and produces zero overfull boxes. **54/115** page text extractions exactly match the accepted layout; **61/115** pages reflow, so the candidate is not silently promoted.
3. **Typography and figure labels:** The main text uses embedded Times New Roman at 12 pt. Some embedded vector-figure labels use smaller DejaVuSans sizes (~5.3–6.3 pt); these need figure-specific legibility review under PU-FMT-039.
4. **Other layout QA:** No tested body text bounding boxes overflow the broad page limits, but automated checks and renderability alone are not full human per-page signoff. The strict candidate raises **320 underfull-box warnings**, requiring a page-by-page spacing review.
5. **Accepted production:** The official formatting acceptance was reported by the user; a signed institutional certificate was not independently reviewed. The old 144-rule audit remains open until missing evidence/overrides are addressed.
